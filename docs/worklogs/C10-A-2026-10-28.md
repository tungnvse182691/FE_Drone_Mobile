## 4. Protocol and crypto evidence

Reference: `OfflineWorkflowEngine.cs:50-61,63-145`; DTO declaration order `OfflineWorkflowDtos.cs:22-43`; direct claim purpose/digest `OfflinePackageAuthentication.cs:11,33-51`; key import/base64 `OfflineCryptoFormat.cs:103-141`.

- DTO-aware serializer uses Web default escaping, declared property order, included null/defaults, lowercase Guid, DateTimeOffset fractional/offset semantics and null-omitted assessment stopConditions.
- FIELD core hash differs from full envelope hash. Repair core hash remains a supplied H4 claim; as in Describe(), actual H4 adapter must validate it against business scope. No arbitrary repair hash becomes dispatch authority.
- Manifest descriptors sort ordinal Guid N. Unique origins and valid hashes required. Direct claim is SHA256(UTF8(`roadguard.h5.direct-sync.v1\0`) || canonicalManifest). Encrypted-package relaxed escaping/signature algorithm is deliberately absent here.
- SPKI P-256 and canonical base64 bounds checked; signature must be 64-byte IEEE P1363, never DER. Native verification provider must additionally validate EC points; no on-device provider is falsely claimed.
- .NET -> Node and Node -> .NET signatures verified, plus wrong key, modified bytes, DER, invalid SPKI, wrong curve, invalid hash, duplicate origins, escaping, Unicode/surrogate pairs, defaults, all six operation kinds and FIELD submission evidence/measurement cases.
- Public test vector was produced by the reference executable. Its ephemeral private signing key was discarded; no private key is saved.
- Explicit supported numeric domain: long values must be safe JS integers; decimal fractional values require `{decimal: lexicalToken}` to preserve scale, bounded to 28 total digits excluding sign/decimal point; doubles are finite fixed-point with magnitude zero or [0.0001, 1e15). Unsupported numeric representations, malformed dates/surrogates and cyclic input fail closed. This is a verified bounded codec, not a promise of parity for every CLR numeric value. Expanding numeric domain requires new reference vectors before enabling it.
- Deep immutable snapshots precede awaits and preserve -0; nonfinite numbers are rejected rather than silently converted to null.
